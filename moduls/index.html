Nous mòduls
via API

Es poden crear aplicacions i integracions mitjançant l'API i els webhooks. La documentació oficial indica que l'API cobreix gran part de les funcionalitats del producte.

Llenguatges: JavaScript / TypeScript, Node.js, PHP, Python, Java, C#, entre d'altres.

fetch("https://api.pipedrive.com/v1/persons?api_token=API_KEY")
  .then(response => response.json())
  .then(data => console.log(data));
